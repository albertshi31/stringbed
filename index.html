      When to clamp Set by your machine

        Where to clamp The same on every machine

        Clamping

        Fixed clamps or flying clamps
        Fixed clamps are mounted on the machine and hold steady. Flying clamps float on the stringbed and grip against the next string, so they lose a little more tension.
        Do not overtighten the mount
        The supports should be snug, not cranked down. Too much pressure can bend the hoop or even crack the frame.

        After you string

        Tension drops, and that is normal
        Strings lose tension from the moment they are strung. About 10 to 15% in the first day is normal, and it keeps dropping more slowly after that. Polyester drops the fastest.
        Pre-stretching
        Pulling the string before you string it takes out some of its early stretch, so the stringbed holds its tension a little better. It is optional. Check the string maker’s advice first.
        Comparing two rackets
        Use a stringbed tension tester, not the number you set on the machine. Different machines give different results from the same setting.

        A string job uses two different knots. One starts a run, the other finishes one.

        Finishing tie-off

        Use this knot after the final string has been tensioned.

        Check: the finished knot sits on the stringbed side, snug against the grommet. Trim the end to about 4 mm.

        More detail

        The knot is called a double half hitch. Zoom in on the diagram to see which strand goes over and which goes under.

        There are fancier tie-offs, like the Parnell, the Pro knot and the Wilson knot, and they all have their fans. Learn this one first. It holds, it is small, and it works on almost every frame.

        It does not matter which way you start. You can bring the loose end up the near side and then pass it under the anchor string, or go under first and come back over. Either way it forms the same loop, and the end tucks back through it. That is one half hitch. Do it twice, the same way both times, and you have a double half hitch. The only difference is whether it turns left or right.

        This is a finishing knot. It holds a string that is already at tension. It is not the starting knot, which gets pulled on hard and needs more bulk.

        Starting knot

        Use this knot to anchor the first cross in a two-piece string job.

        Your current job is one piece, so it does not need a starting knot. The string runs straight on from the mains into the crosses. This lesson is here if you want to learn it anyway.

        More detail

        Where the knot is tied

        In the frame's marked starting hole, next to the first cross. A tensioned main already runs through it. Feed the cross string through the same hole, beside that main, and tie the knot around the main, on the stringbed side, snug against the grommet. It is the same setup as a finishing tie-off. Only the bulk is different.

        From there the string runs along the outside of the frame to the next hole, the first cross hole, and into the stringbed as the first cross.

        Bulk is the difference between this knot and the finishing tie-off. Both sit on the stringbed side, snug against the grommet, but this one gets pulled on straight away, so it has to be fat enough not to slip through the hole.

        A variation you may see

        As you pull the tail through, a third loop opens up. That is the big loop closing down. Some stringers feed the tail through that one as well before pulling it tight, which adds more bulk. Both versions hold. The extra pass is worth knowing if your knot keeps slipping.

        The frame itself shows which holes to use. This app does not decide that, and the positions in the diagrams are only examples. Check them against your racket or the maker's stringing pattern.

        The main difference between machines is how they hold tension after a pull. Choose based on speed, consistency, and how much skill each one needs.
